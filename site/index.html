quietbox

A calmer inbox, on a server you own.

Self-hosted inbox triage for any IMAP mailbox. quietbox moves newsletters, receipts and notifications out of your inbox, and learns from how you file mail yourself.

How it works

You give quietbox a few folders, each with a type: important (your INBOX), later, newsletter, bulk (receipts, notifications), and optionally blackhole (senders you never want to see). They are ordinary folders on your mail server, so any mail app shows them.

  1. quietbox init reads your folders and Sent mail and learns where each sender belongs.
  2. quietbox once (from cron) or quietbox run (a daemon) files new mail as it arrives, using what it learned and detectors for newsletters and automated mail.
  3. Move a message into a folder, or back to INBOX, and that sender follows. One move is enough.
  4. Mail you block waits in the blackhole folder, then goes to Trash after 30 days. quietbox never deletes anything.
# see what it would do first
quietbox init --dry-run
quietbox once --dry-run

# and take it back if you change your mind
quietbox undo --since 1h

Quiet, and careful

  • Mail it cannot place stays in your inbox. Hiding a real person's email is the failure it tries hardest to avoid, so when it errs, it errs toward leaving a newsletter in your inbox, not hiding something you needed.
  • It never expunges or permanently deletes. "Delete" means move to Trash.
  • Every move is written to an audit log before it runs, and undo can reverse any of them.
  • It reads headers only, and never logs message bodies or credentials.

Check it before you trust it

Three read-only commands let you see its judgement on your own mail before it moves anything:

  • quietbox scan shows what it would do with your inbox right now, and why.
  • quietbox eval measures how well it would have done on mail you have already sorted.
  • quietbox explain says why it filed one particular message where it did.

Works with

Fastmail and Gmail
In daily use, with an app password.
Any IMAP server with MOVE and UIDPLUS
Should work, but unverified beyond a Dovecot test server. quietbox check shows what your server offers.
Microsoft 365 and Outlook.com
Not supported. They require OAuth2 for IMAP, which quietbox does not implement.

Not included: a web interface, snooze and reply reminders, digests. It runs on Linux and macOS, not Windows. One quietbox process runs per mailbox, so several accounts means several processes.

Install

One static binary for Linux and macOS, on amd64 and arm64. The script checks the download against the published checksums before it installs anything, and puts quietbox in ~/.local/bin.

curl -fsSL https://quietbox.sh/install.sh | sh

Prefer to read it first? install.sh is short. You can also take an archive from the releases page, or run go install github.com/michele/quietbox/cmd/quietbox@latest. The macOS binaries are not signed, so Gatekeeper refuses the first run: xattr -d com.apple.quarantine quietbox. To keep it running, use the systemd units or the container image.

Status

quietbox is a new project and has not been thoroughly tested. It is in daily use on Fastmail and Gmail accounts. It should work with any IMAP server that supports MOVE and UIDPLUS, but other providers are unverified.

Use it at your own risk. quietbox moves mail and never deletes it, and undo reverses its moves, but it is released under the MIT licence with no warranty. Start with the dry runs, and keep a backup of any mailbox you cannot afford to lose mail from.

What is and is not verified is listed milestone by milestone in the plan.
